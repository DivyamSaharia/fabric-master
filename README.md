# Fabric Master

iPhone-style web app for Hanuman Group's fabric database: yarn master, units with cost per pick and TFO speeds, fabrics with consumption, greige/RFD costing, realisation per pick, profit per pick by unit, spindles per loom for every TFO type, photos, and PDF/WhatsApp/Excel export. Data lives in a Google Sheet in your Drive.

Start with SETUP.md. To try it first, open dist-demo/index.html on any device.

Commands: `npm install`, `npm test`, `npm run build` (dist/), `npm run build:demo` (dist-demo/).
